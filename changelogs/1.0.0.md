### New Features

- **Complete authentication** with Better Auth (sign up, sign in, forgot password).
- **User dashboard** with responsive sidebar and intuitive navigation.
- **Profile management**: edit personal information and avatar.
- **Notification system**: customizable email preferences.
- **Stripe integration** for subscription and payment management.
- **Dark/light mode** with automatic system detection.

### Infrastructure

- Clean Architecture with separation of concerns.
- PostgreSQL database with Prisma ORM.
- File storage on Cloudflare R2.
- Email sending via Resend.
