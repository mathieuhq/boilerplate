### Nouveautés

- **Authentification complète** avec Better Auth (inscription, connexion, mot de passe oublié).
- **Dashboard utilisateur** avec sidebar responsive et navigation intuitive.
- **Gestion du profil** : modification des informations personnelles et avatar.
- **Système de notifications** : préférences email personnalisables.
- **Intégration Stripe** pour la gestion des abonnements et paiements.
- **Mode sombre/clair** avec détection automatique du système.

### Infrastructure

- Architecture Clean Architecture avec séparation des responsabilités.
- Base de données PostgreSQL avec Prisma ORM.
- Stockage fichiers sur Cloudflare R2.
- Envoi d'emails via Resend.
